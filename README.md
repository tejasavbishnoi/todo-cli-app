# CLI To-Do App

A simple command-line To-Do list application built using Python.

## 🚀 Features
- Add tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Data stored locally using JSON

## 🛠️ Tech Stack
- Python (Standard Library)
- JSON (for data storage)

## ▶️ How to Run

1. Clone the repository:
git clone https://github.com/tejasavbishnoi/todo-cli-app.git

2. Navigate to the project folder:
cd todo-cli-app

3. Run the app:
python3 app.py

. ├── app.py ├── tasks.json └── README.md
